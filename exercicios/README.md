Conjunto de exercícios feitos em sala de aula que não estão relacionados a uma lista.

- `academia.c`: Programa que simula sistemas de gestão de alunos matriculados em uma academia. Permite a leitura, escrita e
emissão de relatórios ordenados dos alunos e suas informações (peso, altura, IMC, etc);
- `calcula_MDC.c`: Programa que calcula o Máximo Divisor Comum entre dois números inteiros utilizando o Algoritmo de Euclides;
- `calcula_numero_deputados.c`: Programa que calcula a quantidade de deputados que uma unidade federativa do Brasil deve possuir
com base na sua população;
- `desconto.c`: Programa que calcula o desconto que um cliente receberá com base no valor total da sua compra;
- `equacao_segundo_grau.c`: Programa que calcula as raízes de uma função do segundo grau com base nos valores de A, B e C
utilizando a Fórmula de Bhaskara;
- `imposto_renda.c`: Programa que calcula o salário líquido com base no salário bruto e nas alíquotas do Imposto de Renda (IRPF)
do primeiro semestre de 2024;
- `situacao_aluno.c`: Programa que determina a situação de um aluno com base nas notas da Prova 1, Prova 2 e, opcionalmente, Prova
Final, por meio da lógica utilizada pelos cursos de graduação do CEFET/RJ;
- `valida_data.c`: Programa que avalia se datas enviadas no formato DDMMAAAA é válida.
