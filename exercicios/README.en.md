Collection of exercises made during class that are not related to any lists.

- `academia.c`: Program that mocks management systems used in gyms. Allows reading, writing and the emission of ordered
reports of students and their information (weight, height, BMI, etc);
- `calcula_MDC.c`: Program that calculates the Greatest Common Factor between two integers using the Euclidean Algorithm;
- `calcula_numero_deputados.c`: Program that calculates the maximum amount of deputies a Brazilian state can have based on its population;
- `desconto.c`: Program that calculates the discount a customer will receive based on their purchase's total;
- `equacao_segundo_grau.c`: Program that calculates the roots of a second degree function based on the values of A, B and C
using the Quadratic Formula;
- `imposto_renda.c`: Program that calculates a paycheck after taxes based on the Brazilian IRPF rates of the first semester of 2024;
- `situacao_aluno.c`: Program that determines the semester results of a student based on the Exam 1, Exam 2, and optionally Final Exam grades, through the logic used by CEFET/RJ's bachelor courses;
- `valida_data.c`: Program that validates dates passed in the DDMMYYYY format.
